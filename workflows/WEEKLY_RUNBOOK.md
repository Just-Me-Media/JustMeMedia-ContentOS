# Weekly content runbook

1. Review last week's results, if available.
2. Identify audience questions and timely opportunities.
3. Research 3–4 topics; prioritize primary sources.
4. Record sources and the claims each source supports.
5. Draft original content and adapt to suitable platforms.
6. Run independent factual, editorial and security reviews.
7. Prepare visual briefs and assets.
8. Present the package for user approval.
9. Publish or schedule only after explicit approval.
10. Import performance metrics and record lessons.

Each content item should move through:
IDEA → RESEARCHED → DRAFT → REVIEW → NEEDS_APPROVAL → APPROVED → PUBLISHED

A rejection returns the item to IDEA or ARCHIVED. Approval applies only to the specific version and specified action. Any material edit after approval requires re-approval.
