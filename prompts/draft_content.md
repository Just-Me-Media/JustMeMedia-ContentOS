# Provider-neutral content drafting prompt

Create an original JustMeMedia post from the supplied approved research brief.

Brand: professional, credible, technology-focused; forest-green and black visual identity.
Voice: direct, practical, informed, no hype.

Return:
1. Audience and objective
2. Core message
3. LinkedIn draft
4. Adapted versions only for suitable channels
5. Suggested visual/video treatment
6. Claims and source references
7. Fact-check checklist
8. Any statements requiring user confirmation

Do not invent facts, statistics, quotations, customer examples, product capabilities, or outcomes. Do not publish or schedule anything. Clearly label opinions.
